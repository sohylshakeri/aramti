# گزارش بازطراحی معماری

## انجام‌شده

- فایل‌های ورودی صفحات به ترکیب‌کننده‌ی ساده‌ی بخش‌ها تبدیل شدند.
- منطق و JSX صفحه Home به کامپوننت‌های مخصوص همان صفحه منتقل شد.
- منطق Drag و اسکرول بخش Highlights داخل `HighlightsSection.jsx` قرار گرفت.
- منطق فیلتر، انتخاب نقطه و نمایش تصادفی نظرات داخل `CustomerMapSection.jsx` قرار گرفت.
- قابلیت آزمایشی Pin و بزرگ‌کردن کارت نظر کامل حذف شد.
- نظرات مشتریان و نام اعضای تیم از داده‌ی هاردکد به فایل‌های ترجمه منتقل شدند.
- کامپوننت‌ها و تصویرسازی‌های مخصوص Home از پوشه‌ی UI مشترک خارج شدند.
- صفحات About، Contact و Portfolio نیز به بخش‌های مستقل تقسیم شدند.
- آرایه‌های ناوبری و داده‌های ساختاریافته به `content/` منتقل شدند.
- رنگ‌های تکراری CSS به متغیرهای `:root` منتقل شدند.
- لایه‌ی `mobile.css` به ورودی پروژه اضافه شد.
- مسیرهای `/projects` و `/services` برای لینک‌های فعلی سایت تعریف شدند.
- فایل معماری پروژه با ساختار واقعی جدید هماهنگ شد.

## بررسی‌های انجام‌شده

- تمام فایل‌های JSON ترجمه با موفقیت Parse شدند.
- ۱۷۶ کلید ترجمه‌ی داینامیک در هر دو زبان بررسی شد.
- تمام importهای نسبی بررسی شدند و فایل گمشده‌ای وجود ندارد.
- تمام فایل‌های JavaScript و JSX با parser و transpiler تایپ‌اسکریپت بررسی شدند.
- تعداد آکولادهای فایل‌های CSS بررسی شد.
- کدها و استایل‌های باقی‌مانده از قابلیت Pin حذف شدند.
